ClothesAI - Frontend (React + Vite + Tailwind)


This project is frontend-only. To connect with backend later:
- Backend API base url should be configured in src/utils/api.js (or env .env)
- Example endpoints: /api/products, /api/auth, /api/cart, /api/admin
- You can plug any REST API or GraphQL later.


How to run:
1. npm install
2. npm run dev


Notes:
- Fonts: index.css imports a Google font that supports Vietnamese.
- This scaffold contains mock data in src/utils/mockData.js. Replace with real API calls.
